# Sprint 1 Planning

## Sprint 1 goal:
Set up the CareerConnect project, organize the team, identify requirements,
create GitHub Issues, and implement two basic features for demonstration.

## Planning process
- Every planned item is created as a GitHub Issue.
- Every Issue is added to the Sprint 1 Project.
- Every Issue must have an assignee, status, issue type, priority, effort,
  target date, and any relevant risk or blocker.
- The team workflow is: Not Started → In Progress → Review → Completed.
- User stories and tasks will be tracked using GitHub Issues and labels.

## Sprint 1 Project views
- Board: daily workflow tracking
- Sprint 1 Plan: planning information required for Appendix A
