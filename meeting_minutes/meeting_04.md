## Member Work Breakdown

### Task 1 – User Profile and Resume Management

**Responsible Members:** Melissa Luk and Aya Lakhoitri

**Planned Responsibilities:**
- Allow job seekers to view and edit their professional profiles.
- Display relevant user information, including name and email.
- Support resume upload and replacement.
- Allow users to view their uploaded resume information.
- Integrate the feature with the existing authentication system and Supabase Storage.
- Validate profile updates and resume uploads.
- Prepare acceptance tests for profile editing and resume management.

### Task 2 – Job Search and Job Listing Interface

**Responsible Members:** Amine Ait Yakoub and Sahra Ali

**Planned Responsibilities:**
- Design the job listing interface.
- Display available job opportunities.
- Implement keyword-based job search.
- Add filtering options for location and job category.
- Allow users to view detailed job descriptions.
- Coordinate frontend and backend requirements for job listings.
- Prepare acceptance tests for job searching, filtering, and viewing job details.

### Task 3 – Job Application Submission and Tracking

**Responsible Members:** Saara Noori and Hiba Tyridini

**Planned Responsibilities:**
- Allow job seekers to submit applications for available job postings.
- Associate each application with the relevant user and job posting.
- Store application information in the database.
- Implement application status tracking using the required statuses:
  - Applied
  - Under Review
  - Interview
  - Offered
  - Rejected
- Display confirmation after a successful application submission.
- Prepare acceptance tests for application submission and status tracking.
